# Imagens do site

Coloque nesta pasta as imagens do projeto. A imagem de perfil usada no site está em `maria-perfil.svg` e é provisória; substitua por uma fotografia autorizada da Maria, mantendo o caminho `/images/maria-perfil.svg` ou atualize o `src` no componente.

Sugestão de nomes para novas imagens: `maria-perfil.webp`, `consultorio.webp`, `tratamento-feridas.webp`.
